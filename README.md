## 🤖 Run the AI Service

```bash
cd ai
cd src/api
npm uvicorn main:app --host 0.0.0.0 --port 8000
```

## 🔧 Run the Backend

```bash
cd backend
npm install
npm run dev
```

## 📱 Run the Mobile App

```bash
cd mobile
npm install
npx expo start
```
